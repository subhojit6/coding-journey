# Learning Roadmap

## Goal

Become job-ready for entry-level software development roles by building strong Python fundamentals, DSA skills, practical projects, database knowledge, and interview skills.

**Learning rule:** A topic is not mastered just because I have read or followed a solution. I should be able to explain it and solve a fresh problem independently.

## 1. Python Fundamentals

### Practiced

- [x] Variables and basic data types
- [x] Conditional statements
- [x] `for` and `while` loops
- [x] Basic list operations
- [x] Functions
- [x] Dictionaries and sets in problem-solving exercises
- [x] Exception handling with `try` and `except`
- [x] Basic file-handling projects

### Needs More Practice

- [ ] Tuples, sets, and dictionaries independently
- [ ] String manipulation
- [ ] Functions, parameters, return values, and scope
- [ ] Modules and imports

- [ ] Object-oriented programming
- [ ] Writing clean, reusable code
