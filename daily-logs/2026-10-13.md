## 2. LeetCode #26 — Remove Duplicates from Sorted Array

**Status:** Solved and practiced

### Technique
Two pointers / in-place write pointer.

### What I Learned
- The array is sorted, so duplicate values are adjacent.
- One pointer scans the array.
- Another pointer tracks where the next distinct value should be written.
- The array can be modified in place without creating a second array.

### Complexity
- Time: O(n)
- Extra space: O(1)

### Main Lesson
Two pointers can help solve array problems efficiently while keeping extra space constant.
