## 2. Two-Pointer Techniques

### Problems Practised
- Two Sum II — Input Array Is Sorted (#167).
- Valid Palindrome (#125).
- Squares of a Sorted Array (#977).
- Merge Sorted Array (#88).

### Key Lessons
- Pointer movement should be justified by the problem's properties.
- Sorted input can make pointer-based comparisons useful.
- Backward merging helps protect values that have not yet been processed.
- Boundary conditions matter when one pointer reaches the end of its valid range.

## 3. Space Complexity

### Concepts Reinforced
- O(1) auxiliary space when additional memory remains constant as input grows.
- O(n) auxiliary space when an additional collection grows with the input.
- In-place modification versus creating a separate output list.
- The difference between the input itself and additional memory used by an algorithm.

### Practical Examples
- An additional list containing results may require O(n) space.
- A two-pointer solution that uses only a fixed number of variables can use O(1) auxiliary space.
- Squares of a Sorted Array uses a separate result array, so its auxiliary space is O(n).
